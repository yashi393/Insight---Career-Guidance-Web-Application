**Insight – Career Guidance Web Application**

Insight is a web-based Career Guidance platform designed to help students and early professionals understand the vast opportunities available in today’s technology-driven world. Many individuals struggle to choose the right career path due to a lack of awareness about domains, required skills, job roles, and growth trends. Insight aims to solve this problem by offering personalized tests, detailed domain information, and instant guidance — all in one place.

🚀 Features
1. Career Assessment Tests

Insight provides three different tests to help users understand their strengths and interests:

• Aptitude Test: Evaluates basic logical reasoning, problem-solving skills, and general aptitude to identify suitable career directions.

• Domain Test: Assesses user preferences and interest areas across various tech domains to recommend relevant fields.

• Skill-Based Prediction Test: Analyzes existing skills and predicts which career paths match the user’s current capabilities.

2. Domain Information Hub

A dedicated research section where users can explore detailed information about different technology domains.
For each domain, Insight provides:

--> Domain Description

--> Key Skills Required

--> Salary Range & Career Growth

--> Job Roles & Responsibilities

--> Pros and Cons

--> Industry Demand Overview

*This helps users make informed decisions not just based on tests, but also through deep domain understanding.*

🧑‍💻 User Flow

:::: Users first register or log in to their account.

:::: They can choose any of the three available career assessment tests.

:::: Instant results are displayed based on their responses.

:::: Users can further explore detailed domain insights in the Research Field section.

:::: This combination of tests + domain knowledge helps users confidently choose a suitable career path.

🛠 Tech Stack

Frontend

* HTML5 – for structuring the web pages

* CSS3 – for styling and UI design

* JavaScript – for interactive components, event handling, and dynamic content

Backend

* PHP – handles login, registration, backend logic, and test result processing

* MySQL – used as the relational database for user data, test responses, and domain information

Development & Deployment

* Developed locally using XAMPP (Apache + MySQL)

* Database managed through phpMyAdmin

* Application files uploaded using FileZilla

* Fully hosted on InfinityFree for smooth public access
